# ⚫︎トレシェア

手軽にトレーニング内容を仲間と共有できるコミュニティサービスです。

トレーニング記録の投稿や閲覧を通じて、ユーザー同士がモチベーションを高め合い、継続的な運動習慣の形成を支援します。

## ⚪︎サービス概要  
　・一人だとモチベーションが続かない
　・ジムに通う時間等が確保できない
　・手軽にトレーニングを行い成果を共有したい
　という課題があります。

　トレシェアは、自宅でできるトレーニング内容を簡単に投稿・共有できるサービスとして開発しました。
　ユーザー同士が互いの取り組みを確認し、刺激を受けながら継続的なトレーニングを行える環境を提供します。

## ⚪︎開発背景  
　本アプリは、ハッカソンにてチーム開発で制作したWebアプリケーションです。

## ⚪︎工夫した点  
　1. チーム開発  
　　ハッカソンにおいてチームリーダーとして、メンバー間のタスク調整や進捗管理を行いました。  
　　毎週２回打合せを行い、各自質問や詰まっているところを共有し、チームとして解決できるよう心掛けました。  
　　また、メンバー全員が未経験であったことから、タスクを見失うことのないように具体的に指示をすることを心掛け、打合せ前には打合せ内容を整理して臨むようにしていました。  
　2. データベース設計  
　　投稿とトレーニング項目、投稿とリアクション種類の間には中間テーブルを設けて拡張性の高い設計を行いました。  
　3. AWSへのデプロイ  
　　ハッカソンではローカル環境のみでしたが、その後AWS EC2へデプロイを行い、実際に公開可能なWebサービスとして構築しました。
